# Retail Sales Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a retail sales dataset to uncover meaningful business insights. The analysis focuses on understanding sales trends, customer behavior, product performance, and regional sales distribution using Python data analysis libraries.

This project was completed as part of the **Data Analytics Internship** at **OASIS INFOBYTE**.

---

## 🎯 Objectives

* Load and inspect the retail sales dataset.
* Clean and preprocess the data.
* Analyze sales performance.
* Identify top-selling products and categories.
* Study customer demographics.
* Visualize monthly and quarterly sales trends.
* Generate business insights and recommendations.

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Place the dataset (`SampleSuperstore.csv`) inside the project folder.
5. Open `Retail_Sales_EDA.ipynb`.
6. Run all notebook cells.
