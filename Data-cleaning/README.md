# Data Cleaning

## 📌 Project Overview

This project focuses on cleaning and preprocessing a messy dataset using Python and Pandas. The main goal is to identify and fix common data quality issues such as duplicate records, inconsistent values, missing values, incorrect data types, and outliers.

This project was completed as part of the **OASIS INFOBYTE Data Analytics Internship**.

## 🎯 Objectives

- Inspect the quality of the dataset.
- Identify duplicate records.
- Handle missing values.
- Standardize inconsistent data.
- Convert columns to appropriate data types.
- Handle invalid and outlier values.
- Create a clean dataset ready for further analysis.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Visual Studio Code

## 📂 Files

- `Data_Cleaning.ipynb` – Jupyter Notebook containing the complete data cleaning process.
- `messy_dataset.csv` – Original dataset containing data quality issues.
- `cleaned_dataset.csv` – Final cleaned dataset after preprocessing.

## 🧹 Data Cleaning Steps

The following cleaning operations were performed:

1. Loaded and inspected the dataset.
2. Generated a data quality report.
3. Removed duplicate records.
4. Cleaned unnecessary spaces from names.
5. Standardized gender values.
6. Converted salary values to numeric format.
7. Handled missing Age and Salary values.
8. Identified and handled invalid age values and outliers.
9. Standardized the Joining Date format.
10. Exported the cleaned dataset as `cleaned_dataset.csv`.

## 📊 Result

The dataset was successfully cleaned and transformed into a structured format suitable for further data analysis and machine learning tasks.
